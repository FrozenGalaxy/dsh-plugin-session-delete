# Attribution and porting notes

This is a locally reconstructed DSH 0.2.x port of the MIT-licensed
`lsz-asd/dsh-plugin-session-delete`, keeping the original public package name
`@huanlin/dsh-plugin-session-delete` and Cordis row identifier. The original
project's architecture, endpoint names and tool name are retained.

The updated DSH 0.2.x APIs were cross-checked against the independently
maintained MIT-licensed `SUKJG1052/DSH-Plugin-Session-Delete` fork, especially
its version 1.0.7 implementation and package manifest. This port is not a
byte-for-byte checkout of either upstream repository. The source was rebuilt
locally because direct GitHub archive downloads were unavailable in this
environment; no upstream Git history is represented as local Git history.

Original project: https://github.com/lsz-asd/dsh-plugin-session-delete
Reference port: https://github.com/SUKJG1052/DSH-Plugin-Session-Delete
